# Economic Model with LLM-president

## Идея проекта
Многоуровневая экономическая симуляция, где **домохозяйства и президент** принимают решения при помощи больших языковых моделей (LLM).
Остальные агенты действуют по классическим экономическим правилам.
Модель исследует, как сложность агентов и политические решения президента влияют на экономические показатели.
Для валидации полученной модели, будет проведено сравнение с классическими экономическими моделями.

- Агенты-домохозяйства и Президент могут работать в двух режимах: `rule-based` и `llm-based`.

```bash
pip install perplexity pyyaml matplotlib
```

Далее необходимо для включения LLM мода подключить ключ API perplexity:
```bash
setx PERPLEXITY_API_KEY "your_api_key_here"
```

## Запуск приложения

```bash
python -m src.app 10 --llm-based-president --config config.yaml
```

Параметры:
- `years` - количество периодов симуляции (обязательный)
- `--llm-based-president` / `-pr` - включить LLM для президента
- `--llm-based-households` / `-hh` - включить LLM для домохозяйств
- `--president-setup` / `-ps` - настройка поведения президента (текст)
- `--config` - путь к конфигу (по умолчанию `config.yaml`)
- `--disable-plots` - не показывать графики
- `--profiling` - включить профилирование

## Стоимость запуска
Вычисляется по формуле cost=0.005*years*((2 if llm-based-households else 0) + (1 if llm-based-president else 0))
